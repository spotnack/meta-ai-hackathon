Spotnack Muse

AI-powered 3D model generation from 2D images

About

Spotnack Muse is a mobile application built for the Meta AI Hackathon. It lets users generate 3D models from 2D images using on-device rectified flow transformers, explore a catalogue of AI-generated shapes, and bookmark favourites.

Features

  • Image-to-3D generation with on-device AI inference.
  • Explore and search a live catalogue of generated shapes.
  • Full-screen 3D viewer powered by Three.js.
  • Bookmark and manage favourite models.
  • Sign in with Google or email and password.

Open Source

The source code is available on GitHub.
